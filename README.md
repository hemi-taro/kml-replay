# KML Replay

## PWA

1. Open `https://hemi-taro.github.io/kml-replay/` while online at least once.
2. On iPad Safari, use Share, then Add to Home Screen.
3. Launch from the Home Screen for offline use after the initial load.
4. Open the published URL while online to receive app updates.
